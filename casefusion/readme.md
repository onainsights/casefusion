# `casefusion`

The runnable entry point of [CaseFusion](https://github.com/onainsights/casefusion): it wires up the API
(`@directus/api`) and the admin app and exposes the `casefusion` CLI (`directus` is kept as an alias).

```bash
casefusion bootstrap   # install or migrate the system tables
casefusion start       # start the API and app
```

CaseFusion is a GPLv3 fork of Directus maintained by Ona Insights. See the repository
[readme](https://github.com/onainsights/casefusion#readme) and `LICENSE-NOTICE.md` for details.
